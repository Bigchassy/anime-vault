# Anime Vault

An anime-themed blog for reviews, character discussions, watch guides,
and original stories.

## Features

- Red, black, and white anime theme
- Mobile-friendly layout
- Article search and category filters
- Article reading view
- Local editor for adding, editing, and deleting posts
- Website export containing saved articles

## Built With

HTML, CSS, and JavaScript.

## Files

- `index.html` — Website structure, styling, and functionality
- `anime-vault.png` — Homepage artwork

## View Locally

Keep both files in the same folder, then open `index.html` in a browser.

## Publishing Articles

Posts save in your browser only. To update the public website:

1. Add or edit articles using “Write a post.”
2. Click “Export website.”
3. Rename the exported file to `index.html`.
4. Upload it to this repository, replacing the existing file.
